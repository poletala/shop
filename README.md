# Интернет-магазин

Учебный проект для портфолио: интерфейс магазина косметики и товаров для ухода.

Приложение демонстрирует работу с React и TypeScript: маршрутизацию, переиспользуемые компоненты, управление состоянием и сохранение данных в браузере. В оформлении используются светлый фон, крупная типографика и зелёный акцент.

## Возможности

- **Каталог:** сетка товаров и фильтрация по бренду через query-параметр в URL.
- **Бренды:** поиск по названию и фильтрация по первой букве.
- **Страница товара:** галерея, описание, цена, добавление в корзину и избранное.
- **Корзина:** изменение количества, удаление позиций, расчёт общей стоимости и состояние пустой корзины.
- **Обратная связь при покупке:** кнопка «Купить» меняется на «В корзине», в шапке появляется индикатор.
- **Избранное:** отдельная страница сохранённых товаров.
- **Акции:** промо-карточки, подборка товаров со скидками и раздел собственной коллекции.
- **Подарочные карты:** выбор номинала 1 000, 3 000, 5 000 или 10 000 ₽ и добавление в общую корзину.
- **Личный кабинет:** локальный вход по имени и почте, восстановление профиля после перезагрузки и выход.
- **Боковая панель профиля:** плавное открытие справа, треть ширины экрана на десктопе и вся ширина на мобильном.
- **Промобаннер:** автоматическое переключение слайдов и ручная навигация.

## Структура проекта

```text
public/
  pics/          # Баннеры и изображения разделов
  products/      # Изображения товаров
src/
  components/    # Шапка, футер, карточки, баннер и общие кнопки
  context/       # AuthContext и общий AuthProvider
  data/          # Моковые товары и акции
  hooks/         # useAuth, useCart, useFavorites
  pages/         # Страницы приложения
  router/        # Настройка маршрутов
  theme/         # Общая тема Material UI
  App.tsx        # Подключение темы, авторизации и роутера
  main.tsx       # Точка входа
```

### Основные маршруты

| Путь | Раздел |
| --- | --- |
| `/catalog` | Каталог; `?brand=VT` — пример фильтра по бренду |
| `/product/:id` | Страница товара |
| `/brands` | Поиск и выбор бренда |
| `/promotions` | Акции |
| `/promotions60` | Товары со скидками |
| `/ours` | Собственная коллекция |
| `/saved` | Избранное |
| `/cart` | Корзина |
| `/gift` | Подарочные карты |
| `/account` | Панель личного кабинета |

## Работа с состоянием

`AuthProvider` хранит пользователя в общем контексте; `useAuth` предоставляет профиль и действия входа и выхода. Шапка и личный кабинет используют одно состояние.

`useCart` управляет товарами, подарочными картами и их количеством. После изменения корзины событие `cart-updated` обновляет её состояние в компонентах текущей вкладки. `useFavorites` управляет списком сохранённых товаров.

| Ключ localStorage | Данные |
| --- | --- |
| `user` | Имя и e-mail текущего пользователя |
| `cart` | Позиции корзины, количество и данные подарочных карт |
| `favorites` | Идентификаторы избранных товаров |

Корзина и избранное привязаны к браузеру, а не к профилю. Выход из аккаунта не удаляет их.
